SWAZY'S LITTLE LOVE WEBSITE ♡

FILES
- index.html: the complete website (HTML + CSS + JavaScript)
- assets/: add your own photos and music here

ADD YOUR PHOTOS
1. Put three photos in the assets folder.
2. Name them exactly:
   memory-1.jpg
   memory-2.jpg
   memory-3.jpg
3. If your photos are PNG files, either convert them to JPG or edit the matching src values in index.html.

ADD THE SONG
1. Place a legally obtained MP3 file you are allowed to use in the assets folder.
2. Name it exactly: love-story.mp3
3. The website does not include the song audio. Make sure you have permission to use the recording before publishing it publicly.
4. Browsers do not allow autoplay in many cases; Swazy can press play on the audio player.

PREVIEW IN VS CODE
- Open this folder in VS Code.
- Open index.html in a browser, or use the Live Server extension.
- The Google Fonts import needs internet access; fallback fonts are included.

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository.
2. Upload index.html and the assets folder (including any photos/audio you have permission to publish).
3. Open the repository's Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub to publish the site, then open the URL shown in Settings > Pages.

PRIVACY
Only add photos you are comfortable sharing on a public website. A public GitHub Pages site can be viewed by anyone with the link, and the URL may be shared.
